# GoSwitcher

**GoSwitcher** — умный, легковесный и кроссплатформенный (Windows & Linux) переключатель раскладки клавиатуры и интеллектуальный ассистент набора текста, написанный на Go.

Создан с упором на нужды разработчиков и DevOps/SRE-инженеров: программа использует вероятностную модель **Наивного Байеса**, **топографию клавиатуры** и **синтаксический парсер**, чтобы исправлять раскладку и опечатки в обычном тексте, но **никогда не ломать** консольные команды, флаги, пути, IP-адреса и код.

---

## Стек и технологии

* **Ядро и системный уровень:**
  * **Go (Golang 1.21+)** — единая кроссплатформенная кодовая база с условной компиляцией (`//go:build windows` / `linux`) и атомарными операциями (`sync/atomic`) для потокобезопасного перехвата ввода.
  * **Windows API (`golang.org/x/sys/windows`)** — низкоуровневые глобальные хуки клавиатуры (`WH_KEYBOARD_LL`), инъекция Unicode-символов через `SendInput`, управление буфером обмена и раскладками окон.
  * **Linux Input & Wayland/X11** — прямое чтение сырых событий с аппаратных устройств (`/dev/input/event*`), эмуляция виртуальной клавиатуры через ядерный интерфейс `/dev/uinput`, интеграция с KDE Plasma (D-Bus / KWin Scripting), `wl-clipboard` / `xclip`.
* **ИИ и лингвистический движок:**
  * **Наивный байесовский классификатор (Naive Bayes)** — вероятностная модель на позиционных символьных N-граммах (2–4 символа с маркерами границ `^` и `$`) со сглаживанием Лапласа (`model.json`).
  * **Марковские цепи 1-го порядка** — учет языка предыдущего слова для динамической корректировки порога уверенности и контекстной замены одиночных предлогов.
  * **Топологический анализ QWERTY (Keyboard Heatmap)** — расчет евклидова расстояния между клавишами на физической раскладке и адаптация весов под индивидуальную статистику опечаток (`heatmap.json`).
* **Интерфейс и дистрибуция:**
  * **Встроенный веб-сервер (`net/http`, `embed`)** — локальная панель управления и REST API, вшитые внутрь единого бинарного файла без внешних зависимостей.
  * **Упаковка и CI/CD** — генерация Windows-ресурсов (`rsrc.syso`), сборка инсталлятора через Inno Setup (`setup.iss`) и автоматизированная сборка RPM-пакетов через GitHub Actions.

## Ключевые возможности

### 1. ИИ-ядро, Fast-Track и Адаптивная Моторика
- **Наивный Байес + Сглаживание Лапласа:** Оценка позиционных N-грамм для мгновенного определения языка без «слепых зон» на редких словах.
- **Fast-Track для коротких слов и предлогов:** Мгновенная замена частых коротких слов (`lf` → `да`, `ye` → `ну`, `yt` → `не`) и контекстная конвертация одиночных предлогов (`d` → `в`, `f` → `а`, `j` → `о`) с опорой на язык предыдущего слова.
- **LiveTypo (Переключение на лету):** Автоматически исправляет очевидную абракадабру (например, `ghbd` → `прив`) ещё **до нажатия пробела** (настраивается с 3-го по 6-й символ).
- **Топография клавиатуры и Heatmap:** Вычисляет евклидово расстояние пробега пальцев по QWERTY-сетке. Программа запоминает, на каких именно клавишах вы чаще всего ошибаетесь, и адаптирует порог срабатывания под вашу моторику.

### 2. DevOps-эвристики и Защита синтаксиса
- **Умный парсер IT-паттернов и дефисов:** Автоматически распознаёт и защищает от перевода `snake_case`, сложные `kebab-case` ключи, IP-адреса (`192.168.88.1`) и версии пакетов (`lib-32`), но при этом корректно переводит обычные слова с дефисом (`xnj-nj` → `что-то`).
- **Блокировка путей и флагов:** Консольные аргументы (`-rf`, `--help`) и пути файловой системы (`/opt/winbox`, `\Users`) не ломаются при случайном вводе в русской раскладке.
- **Умная токенизация и пунктуация:** Скобки, кавычки и операторы (`"`, `'`, `(`, `{`, `=`) выступают разделителями слов, при этом символы `[ ] ; ' , .` не разрывают русские слова (`;t` → `же`, `[орошо` → `хорошо`).
- **Умный Caps Lock и сброс контекста:** Корректно нормализует случайную инверсию регистра при включённом Caps Lock (`пРИВЕТ` → `Hello`) и автоматически сбрасывает буфер слова при ручной смене раскладки через `Ctrl` / `Alt` / `Win`.

### 3. Автокоррекция, «Ё» и Работа с выделением
- **Словарная автокоррекция (RU / EN):** Исправляет частые опечатки (`вообщем` → `в общем`, `teh` → `the`) и расставляет букву **«Ё»** по правилам русского языка (`еще` → `ещё`, `надежный` → `надёжный`) **без переключения раскладки** и с сохранением исходного регистра.
- **Трансформация выделенного текста:** Горячие клавиши работают как с последним набранным словом, так и с произвольным выделенным фрагментом текста (с сохранением и восстановлением буфера обмена).
- **Циклическая смена регистра:** Переключение слова или выделенной фразы по кругу: `нижний` → `ВЕРХНИЙ` → `Заглавный` (по умолчанию `Shift + Pause`).
- **Обучение на лету:**
  - **Двойной `Shift`** (или полное стирание через `Backspace`) — мгновенно отменяет автозамену и навсегда заносит слово в `Exceptions`.
  - **`Pause / Break`** — принудительно переводит слово и добавляет его в `ForceConvert`.

### 4. Web UI Дашборд
Встроенный локальный веб-интерфейс (`[http://127.0.0.1:8765](http://127.0.0.1:8765)`), доступный из системного трея:
- **Статистика в реальном времени:** Счётчик сэкономленных нажатий, процент точности модели, лента дистанций последних слов и интерактивная **тепловая карта клавиатуры**.
- **Управление словарями:** Интерактивные теги для `Exceptions`, `ForceConvert` и `Custom Vocabulary` с кнопкой **«Переобучить ИИ»** в фоне без перезапуска приложения.
- **Горячая перезагрузка настроек:** Все пороги, фильтры и `Blacklist` процессов применяются мгновенно через `RWMutex`.

## Сборка и запуск

### Предварительные требования
- **Go:** версия **1.21** или выше.
- **Языковая модель (`model.json`):** должна находиться в корне проекта перед сборкой (генерируется флагом `-learn` из словарей `words_ru.txt` и `words_en.txt`).

### Windows

1. **Установка утилит для сборки ресурсов (опционально):**
   ```powershell
   # Для вшивания icon.ico внутрь исполняемого файла
   go install github.com/akavel/rsrc@latest
   ```

2. **Обучение модели** (если в папке нет `model.json`):
   ```powershell
   go run . -learn
   ```

3. **Генерация ресурсов и релизная сборка** (скрытое GUI-приложение без консольного окна):
   ```powershell
   rsrc -ico icon.ico -o rsrc.syso
   go build -ldflags="-s -w -H=windowsgui" -trimpath -o GoSwitcher.exe .
   ```

4. **Сборка инсталлятора (Inno Setup):**
   ```powershell
   iscc setup.iss
   ```
   Готовый установщик `GoSwitcher_Setup_v1.4.11.exe` появится в папке `dist\`.

---

### Linux (openSUSE Tumbleweed / ALT Linux / KDE Plasma)

Linux-версия работает напрямую через подсистему ядра **`evdev`** и **`uinput`**, что обеспечивает полную работоспособность как в **Wayland**, так и в **X11**.

1. **Установка системных зависимостей (CGO, GTK3, трей и буфер обмена):**
   - **openSUSE Tumbleweed / Leap:**
     ```bash
     sudo zypper install -y gcc pkg-config gtk3-devel libayatana-appindicator3-devel wl-clipboard xclip
     ```
   - **Ubuntu / Debian:**
     ```bash
     sudo apt update && sudo apt install -y build-essential pkg-config libgtk-3-dev libayatana-appindicator3-dev wl-clipboard xclip
     ```
   - **Fedora:**
     ```bash
     sudo dnf install -y gcc pkg-config gtk3-devel libayatana-appindicator-gtk3-devel wl-clipboard xclip
     ```
   *(Опционально для Wayland / KDE Plasma: установите `kdotool` для определения активного окна при работе `Blacklist`).*

2. **Настройка прав доступа к `/dev/input` и `/dev/uinput`** (для запуска без `sudo`):
   ```bash
   sudo usermod -aG input $USER
   echo 'KERNEL=="uinput", MODE="0660", GROUP="input", OPTIONS+="static_node=uinput"' | sudo tee /etc/udev/rules.d/99-goswitcher.rules
   sudo udevadm control --reload-rules && sudo udevadm trigger
   ```
   *(После добавления пользователя в группу `input` необходимо один раз перелогиниться в сессию).*

3. **Сборка бинарника или RPM-пакета:**
   ```bash
   # Быстрая локальная сборка
   CGO_ENABLED=1 go build -ldflags="-s -w" -trimpath -o goswitcher .

   # Сборка RPM-пакета (openSUSE Tumbleweed)
   ./build_rpm.sh
   sudo zypper install --allow-unsigned-rpm ~/rpmbuild/RPMS/x86_64/goswitcher-1.4.11-1*.rpm
   ```

4. **Запуск через systemd (пользовательский юнит):**
   ```bash
   systemctl --user enable --now goswitcher.service
   ```

## Структура проекта

```text
GoSwitcher/
├── main.go               # Точка входа, HTTP-сервер Web UI, трей и управление настройками/статистикой
├── engine.go             # Единый кроссплатформенный движок состояний и логика принятия решений
├── ai.go                 # Наивный Байес, N-граммы, топография QWERTY и словари автокоррекции
├── text_utils.go         # Чистые функции маппинга раскладок, парсинг IT-паттернов и смена регистра
├── hook_windows.go       # Тонкий клиент перехвата ввода Win32 API (WH_KEYBOARD_LL) и буфера обмена
├── hook_linux.go         # Тонкий клиент перехвата ввода Linux (/dev/input/event* + /dev/uinput)
├── platform_windows.go   # Single-instance mutex, реестр автозапуска и открытие браузера (Windows)
├── platform_linux.go     # Flock, XDG Autostart (.desktop) и xdg-open (Linux)
├── web/
│   └── index.html        # Встраиваемый дашборд настроек, статистики и тепловой карты
├── setup.iss             # Скрипт сборки установщика Inno Setup для Windows
├── goswitcher.spec       # Spec-файл для сборки RPM-пакета (openSUSE / ALT Linux)
├── build_rpm.sh          # Скрипт автоматической сборки RPM с вендорингом зависимостей
├── icon.ico              # Иконка приложения для трея и инсталлятора
├── rsrc.syso             # Скомпилированный ресурс Windows с вшитой иконкой
└── model.json            # Обученная модель (генерируется флагом -learn)
```
