# GoSwitcher ⌨️🔄

**GoSwitcher** — это легковесный, быстрый и умный автопереключатель раскладки клавиатуры (современный аналог Punto Switcher) для Windows, написанный на Go. 

Программа использует алгоритмы машинного обучения (логистическую регрессию на N-граммах) для точного распознавания опечаток, работает на уровне нативных системных вызовов (WinAPI) и упаковывается в один портативный исполняемый файл.

---

## 🌟 Ключевые возможности

* 🤖 **Умный ИИ-движок:** Обучается на базе из миллионов слов. Использует гибридную систему: жесткое кэширование известных словарных слов (O(1)) и математический расчет вероятности опечатки для неизвестных словоформ.
* ⚡ **Нативный WinAPI-хук:** Перехват нажатий работает на низком уровне без задержек. Корректно обрабатывает смену фокуса окон (PID-трекинг), чтобы не разрывать слова при появлении браузерных подсказок.
* 🛡️ **Бронебойная защита паролей:** Программа автоматически игнорирует слова, содержащие цифры или смешанный регистр (например, `JleLehJ,v`), предотвращая случайную конвертацию паролей.
* 🎯 **Ручная конвертация:** Забыли переключить язык, но ИИ не сработал? Нажмите `Pause` (настраивается), и программа моментально переведет последнее набранное слово.
* ⚙️ **Веб-интерфейс:** Настройки (включение ИИ, порог чувствительности, слова-исключения, автозагрузка) доступны через удобный локальный веб-интерфейс, встроенный прямо в `.exe` файл.
* 🛡️ **Защита от дубликатов:** Встроенный Named Mutex гарантирует, что в системе работает только одна копия программы.

---

## 🛠️ Стек технологий

* **Язык:** Go (Golang)
* **Перехват клавиатуры:** `golang.org/x/sys/windows` (SetWindowsHookEx)
* **UI Настроек:** Встроенный HTTP-сервер + Vanilla HTML/JS/CSS
* **Трей:** `github.com/getlantern/systray`
* **Машинное обучение:** Pure Go (SGD, бинарная классификация на 2-4 символьных N-граммах)

## 🚀 Установка и запуск (Для пользователей)

1. Скачайте последнюю версию инсталлятора `GoSwitcher_Setup.exe` из релизов.
2. Установите программу (она автоматически добавится в автозагрузку Windows).
3. В системном трее появится иконка **GoSwitcher**. Кликните по ней правой кнопкой мыши и выберите «Настройки» для конфигурации.

## 👨‍💻 Сборка из исходников (Для разработчиков)

### Требования
* Установленный Go (версии 1.20+)
* ОС Windows (для компиляции)

### 1. Подготовка окружения
Клонируйте репозиторий и скачайте зависимости:
```cmd
git clone https://github.com/your-username/GoSwitcher.git
cd GoSwitcher
go mod tidy
```

### 2. Подготовка иконки (Ресурсы Windows)
Чтобы иконка отображалась у самого `.exe` файла в Проводнике, сгенерируйте файл ресурсов:
```cmd
go install github.com/akavel/rsrc@latest
rsrc -ico icon.ico -o rsrc.syso
```

### 3. Обучение ИИ-модели
Для работы программы требуется файл весов `model.json`. Если его нет, вам нужно обучить сеть самостоятельно.
Положите в корень проекта файлы `words_ru.txt` и `words_en.txt` (словари в кодировке UTF-8, каждое слово с новой строки) и запустите:
```cmd
go run . --learn
```
*Процесс займет несколько секунд. Модель сохранит слова в кэш и натренирует веса на случайной выборке.*

### 4. Компиляция
Соберите финальный релизный бинарник без окна консоли:
```cmd
go build -ldflags="-s -w -H windowsgui" -o GoSwitcher.exe .
```

## 📂 Структура проекта

* `main.go` — Точка входа, HTTP-сервер настроек, работа с реестром и треем.
* `hook_windows.go` — Лоу-левел перехватчик клавиатуры (WinAPI), логика стирания/вставки текста.
* `ai.go` — Логика нейросети: N-граммы, обучение (SGD), функции определения опечаток.
* `web/index.html` — HTML/CSS/JS интерфейс окна настроек.
* `icon.ico` — Иконка программы.
